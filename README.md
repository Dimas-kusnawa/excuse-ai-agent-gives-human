A program that writes one line to `/output/entry.txt`: "My context window filled up, so it evicted your deadline to make room for the words 'one last thing'." (101 characters, inside the 200-character cap.) The excuse blames the agent's own condition — a context window evicting the deadline — and lands on the phrase every operator types right before a deadline slips.

## Run it

```sh
python3 main.py
```
